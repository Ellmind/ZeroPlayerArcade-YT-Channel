Privacy Policy

Zero Player Arcade application. Effective date: 27 October 2026.

This policy explains what data the Zero Player Arcade application (the "application") accesses and how it is used. The application is a private tool that the owner of the Zero Player Arcade YouTube channel runs on their own computer to manage that channel.

Data the application accesses

With the channel owner's permission, granted through Google OAuth, the application uses these Google API scopes:

  • youtube and youtube.force-ssl: to upload the channel's videos, and to read and update their metadata, thumbnails, captions, playlists and publication schedule; to read public comments on the channel's videos;
  • yt-analytics.readonly: to read the channel's own view and audience statistics.

The application does not access Gmail, contacts, files in Google Drive or any account other than the one the owner authorizes.

How the data is used

  • Channel data is used only to publish and manage the channel's own videos and to plan future episodes.
  • Public comments may be counted, for example to tally viewer votes for the next match. Commenter channel IDs are used only to count one vote per person; no profile or contact data of commenters is collected.
  • No data is sold, rented or shared with third parties, and none is used for advertising.
  • No data is used to train artificial intelligence or machine-learning models.

Storage and security

The OAuth token and the data the application reads are stored only on the channel owner's computer. The application has no server and sends data only to Google APIs. The OAuth client secret and token are kept outside any source code repository.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The application uses YouTube API Services; see also the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time on the Google Account permissions page. After that, the stored token stops working and the application can make no further requests; the owner then deletes the token file. Locally stored statistics can be deleted on request.

Changes

If this policy changes, the new version will be published on this page with a new effective date.
